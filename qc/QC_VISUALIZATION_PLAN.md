# 全流程配准 QC 可视化工具设计与实施计划

> 本文是后续 Codex 的实施依据。开始开发前，应先阅读本文件、仓库根目录
> `README.md`、`qc/README.md`，再检查当前工作区和相关测试。不要跳过坐标验证，
> 也不要在没有证据时猜测原始图像、检测结果和配准结果之间的轴顺序。

## 1. 项目目标

在检测、z-link、共定位和配准全部完成后，提供一个交互式 QC 工具，让使用者能够：

1. 从最终脑区、细胞 ID、全局像素坐标或整脑视图中的点击位置开始定位。
2. 找到对应的原始通道、原始 tile、原始 TIFF 切片和 tile 内局部坐标。
3. 在同一个局部视野中叠加每一级检测结果、最终细胞和配准脑区边界。
4. 判断错误来自原始检测、z-link、共定位、坐标转换还是最终归区。
5. 保存结构化人工判定、备注、截图和汇总报告。

目标数据链如下：

```text
最终脑区 / 最终细胞 / 任意全局坐标
                  ↓
         原始全局像素坐标
                  ↓
       原始 tile、TIFF 和局部坐标
                  ↓
     s1 → s2 → s3 → s4 → registration
                  ↓
        人工判定、截图和汇总报告
```

这个工具用于检查已有检测和配准结果。检测漏检率的严格估计仍由盲 crop 标注流程
负责；不要用“从最终细胞抽样”估计 recall，因为漏掉的细胞不会进入抽样总体。

## 2. 现有基础

开发时优先扩展现有模块，不新建一套重复的数据读取和坐标逻辑：

- `qc/view_detection_qc.py`
  - 已能显示原始图像、s1/s2/s3/s4 检测框、最终细胞和脑区边界。
  - 已有按脑区抽样、快照、漏斗统计和人工判定框架。
  - 当前工作区可能已经含有按 cell ID/全局坐标定位的初步实现；继续开发前先检查
    `git diff` 和测试，不要重复实现或覆盖现有改动。
- `qc/detection_boxes.py`
  - 负责读取和统一各阶段检测框。
  - 大型 CSV 使用分块读取，不能改成整表加载。
- `qc/region_cells.py`
  - 负责加载最终细胞、脑区选择、标签回查、边界深度和局部图像数据源。
- `qc/crop_geometry.py`
  - 包含 TeraStitcher tile 网格及全局像素到原始 tile 的换算。
- `single_sample.py`
  - 已有将重定位后的标签恢复到原始碎片位置的逻辑，应复用其数学和数据约定。
- `qc/cut_crops.py`、`qc/annotate_crop.py`、`qc/score_crops.py`
  - 是独立的盲法漏检评估流程，不应与本工具的非盲人工判定输出目录混用。

## 3. 核心使用场景

### 3.1 按脑区抽样

用户选择脑区、细胞类别和抽样方式，从最终 `cell_registration.csv` 中选择细胞。
支持随机抽样和优先抽取区域边界附近的细胞。

主要回答：

- 最终归区是否符合原始组织位置。
- 边界附近的归区是否稳定。
- 某类细胞在特定脑区中的错误是否集中。

### 3.2 按细胞 ID 定位

输入稳定标识，例如：

```text
glia_GFP_Sox9:1203
```

工具直接打开该细胞对应的原始图像和完整流程证据。搜索范围必须是整个最终细胞表，
不能受当前 `regions` 或 `classes` 抽样过滤限制。

### 3.3 按任意全局坐标定位

输入全局像素坐标：

```text
x = 15342
y = 28761
z = 832
```

工具应提供两个独立结果：

1. 直接以输入坐标为中心裁取原始图像，即使附近没有最终细胞也能查看。
2. 查找附近最近的最终细胞，显示细胞 ID 和物理距离，但不能擅自把查看中心替换成
   最近细胞。

任意坐标查看是排查漏检、空白区、边界错误和拼接问题的必要能力。

### 3.4 从整脑视图点击定位

在配准样本图像或 `labels_in_sample` 上点击后，局部原图视图跳转到对应全局位置。
反向操作也要成立：在局部视图翻页或输入坐标后，整脑视图中的位置标记同步移动。

## 4. 用户界面

建议使用一个 napari 窗口，布局分为整脑导航、局部原图、流程证据和底部状态区：

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 样本、输入坐标、细胞 ID、脑区、类别、当前判定                       │
├──────────────────────┬──────────────────────────┬────────────────────┤
│ 整脑导航             │ 原始图像                 │ 全流程证据          │
│ registration image   │ RFP / GFP / Sox9         │ s1 tile 检测       │
│ labels_in_sample     │ 原始 tile 拼接           │ s2 全局 2D         │
│ selected region      │ 检测框叠加               │ s3 z-link          │
│ final cells          │ 当前坐标十字线           │ s4 共定位           │
│ local-window box     │ tile 接缝                 │ final registration │
├──────────────────────┴──────────────────────────┴────────────────────┤
│ 源文件、局部坐标、脑区、边界距离、signal ratio、人工判定和备注       │
└──────────────────────────────────────────────────────────────────────┘
```

### 4.1 整脑导航区

显示：

- 配准使用的样本图像。
- `*_labels_in_sample.nii.gz`。
- 当前选择的脑区及其后代。
- 最终注册细胞。
- 当前局部窗口在整脑中的范围。

交互：

- 在任意正交视图点击定位。
- 按脑区名称、缩写或 ID 搜索。
- 按最终类别过滤细胞。
- 显示光标下脑区的完整祖先链。
- 切换冠状、矢状和水平视图。

### 4.2 局部原图区

显示所有配置的原始通道，支持单层和一定厚度的 z 最大投影。各证据层必须能单独
开关，建议使用以下稳定样式：

| 内容 | 样式 |
|---|---|
| s1 逐 tile 检测 | 点线框 |
| s2 全局 2D 检测 | 细虚线框 |
| s3 z-link 后对象 | 实线框 |
| s4 共定位结果 | 粗虚线框 |
| 最终注册细胞 | 空心圆 |
| 当前目标位置 | 白色十字 |
| 目标脑区边界 | 黄色轮廓 |
| tile 接缝 | 半透明青色线 |

需要提供：

- 通道开关和独立对比度。
- 各阶段图层开关。
- z 层滑动和 MIP 厚度控制。
- tile 来源切换。
- 截图按钮。
- 对当前坐标周围一定范围内对象的列表。

### 4.3 全流程证据区

针对当前目标展示其流程轨迹，例如：

```text
RFP s2: 3 个二维框 → RFP s3: 1 个三维对象
GFP s2: 4 个二维框 → GFP s3: 1 个三维对象
Sox9 s3: 1 个候选
共定位结果: glia_GFP_Sox9
最终细胞表: 已进入
最终脑区: SSp-bfd
```

同时显示：

- 每一级的坐标、尺寸和类别。
- s2 到 s3 的合并关系。
- s3 到 s4 的共定位关系或最近距离。
- s4 与 `cell_registration.csv` 是否精确对应。
- 细胞表脑区与 `labels_in_sample` 回查脑区是否一致。
- 到目标区域边界的有符号物理距离。
- signal ratio。
- 所有覆盖目标的原始 tile 和 TIFF。

## 5. 坐标契约

所有模块必须遵守同一个坐标契约。禁止在 GUI 回调里临时拼接轴交换、缩放或偏移。

### 5.1 四种坐标空间

| 坐标空间 | 表示 | 用途 |
|---|---|---|
| 原始全局像素 | `(x, y, z)` | 检测框及细胞的原始位置 |
| 物理空间 | `(x_um, y_um, z_um)` | 不同分辨率数据之间的桥梁 |
| 样本配准网格 | `(x_label, y_label, z_label)` | 查询 `labels_in_sample` |
| 图谱空间 | atlas voxel 或物理坐标 | 展示最终图谱位置 |

数组进入 napari 时通常是 `(z, y, x)`；磁盘表格和所有坐标 API 统一使用 `(x, y, z)`。
任何轴交换只允许发生在明确的显示边界。

### 5.2 全局像素到物理空间

```text
physical_um = global_pixel_xyz * cell_voxel_um_xyz
```

### 5.3 物理空间到标签体素

```text
label_voxel_xyz =
    (physical_um - label_origin_um) / label_spacing_um
```

实现不能假设标签 origin 恒为零，也不能假设 spacing 各向同性。

### 5.4 全局像素到 tile

沿用 brain detector 和 `qc/crop_geometry.py` 的约定：

```text
tile_x0 = ABS_H - min(ABS_H)
tile_y0 = ABS_V - min(ABS_V)
tile_z0 = max(ABS_D) - ABS_D

local_x = global_x - tile_x0
local_y = global_y - tile_y0
local_z_0idx = global_z - 1 + tile_z0
```

通道配置中的 `offset_px` 必须参与源图像定位，并在界面中明确显示。定位结果至少应
包含：

```text
输入全局坐标
物理坐标
标签体素坐标
原始 tile 名称
tile 内 x/y/z（0 起）
原始 TIFF 完整路径
所用通道偏移
```

## 6. 重叠 tile

一个全局位置可能同时被多个 tile 覆盖。工具必须保留全部候选，不能静默选择第一项。

默认策略：

1. 列出所有覆盖该位置且存在有效 z 切片的 tile。
2. 默认显示 tile 中心距离目标最近的一项。
3. 允许切换源 tile，或并排比较多个来源。
4. 标明目标到 tile 边缘的距离。
5. 人工判定中记录实际使用的源 tile。

这样才能区分检测错误、tile 接缝问题、单个 tile 成像质量问题和拼接坐标错误。

## 7. 各阶段数据来源

| 阶段 | 数据来源 | 主要检查 |
|---|---|---|
| 原始图像 | 各通道 tile TIFF | 原始信号是否存在 |
| s1 | `1_tile_2d_filtered/` | tile 内是否检出 |
| s2 | `2_global_2d_raw/` | 全局转换是否正确 |
| s3 | `3_channel_3d/` | z-link 是否过并或欠并 |
| s4 | `4_colocalization/coloc_result.csv` | 共定位是否正确 |
| 最终细胞 | `cell_registration.csv` | 是否进入最终统计 |
| 样本标签 | `*_labels_in_sample.nii.gz` | 样本空间脑区边界 |
| 图谱结果 | 配准变换后的坐标 | 最终图谱位置和归区 |

启动时必须检查：

- s4 与最终细胞表的坐标和类别是否逐行精确对应。
- `cell_voxel_um` 是否能复现细胞表保存的样本网格坐标。
- tile XML 是否覆盖目标位置。
- 各通道的 tile 网格、体素尺寸和偏移是否明确。
- 标签图 spacing、origin 和 direction 是否有效。
- 配置快照是否属于当前 run。

失败项应显示为明显警告。坐标契约无法确认时，禁止用看似合理的默认值继续绘制。

## 8. 人工判定结构

不要把所有错误压缩成一个“对/错”。至少拆成三个维度。

### 8.1 检测判定

- `correct`
- `false_positive`
- `missed_nearby_cell`
- `uncertain`

### 8.2 合并和共定位判定

- `correct`
- `over_merge`
- `under_merge`
- `colocalization_wrong`
- `channel_alignment_problem`

### 8.3 配准判定

- `correct`
- `wrong_region`
- `boundary_uncertain`
- `registration_offset`
- `reposition_mismatch`

每条判定至少保存：

```text
run_dir
target_kind
cell_id（任意坐标时可为空）
global_x, global_y, global_z
source_tile
source_tiff
table_region_id
lookup_region_id
boundary_depth_um
detection_verdict
colocalization_verdict
registration_verdict
note
timestamp
```

保存应采用安全重写或原子替换，使程序崩溃最多丢失当前一次操作。输出格式应能继续
读取旧版 `verdicts.csv`，必要时增加显式 schema version。

## 9. Fragment reposition 样本

这类样本同时存在原始展开空间和配准使用的合拢空间：

```text
原始采集空间 ← fragment transform → 配准使用空间
```

界面应提供明确空间开关：

```text
显示空间：原始采集空间 / 配准使用空间
```

原始空间：

- 显示原始 TIFF。
- 使用细胞表保留的原始全局坐标。
- 使用恢复到原始碎片位置的脑区标签。

配准空间：

- 显示 reposition 后的样本。
- 使用重定位后的细胞位置。
- 使用正常的 `labels_in_sample`。

实现时复用 `single_sample.py` 和 `registration_ants.reposition` 的现有逻辑。若无法生成
原始空间标签，应隐藏该空间中的脑区边界并显示原因；禁止把合拢空间的边界直接盖在
原始展开图像上。

## 10. 性能设计

s2 文件可能包含数千万行，设计必须满足：

1. 启动时只加载细胞表、本体、标签元数据和必要的低分辨率导航数据。
2. 检测 CSV 根据当前局部窗口分块扫描，不能整表常驻内存。
3. 已访问窗口缓存在内存中，并限制缓存大小。
4. 当前页面显示后，后台只预取前后相邻位置。
5. 原始 TIFF 只读取当前需要的 z 层。
6. 标签局部边界按需读取或重采样。

可选的磁盘空间索引缓存必须记录源文件路径、大小和修改时间；任一源文件变化时缓存
自动失效，不能继续使用陈旧索引。

## 11. 输出目录

建议输出结构：

```text
qc_output/
├── verdicts.csv
├── sessions/
│   └── session_YYYYMMDD_HHMM.json
├── screenshots/
│   └── <target_id>.png
└── reports/
    ├── summary.csv
    └── summary.html
```

`summary.html` 后续可汇总：

- 各阶段错误比例。
- 各类别和脑区的错误比例。
- 边界距离与错误率的关系。
- tile 接缝附近的错误率。
- signal ratio 分布。
- 异常细胞截图和源文件链接。

- [ ] 返回所有覆盖坐标的原始 tile、TIFF 和局部坐标。
- [ ] 完成全局像素、物理空间、标签体素之间的双向换算。

z 起点和通道偏移后，仍能精确还原输入全局坐标。

### 阶段 B：局部全流程查看器

任务：

- [ ] 支持 cell ID 和任意全局坐标入口。
- [ ] 显示所有原始通道。

### 阶段 C：整脑点击联动

### 阶段 D：reposition 支持

任务：

- [ ] 读取 run 配置快照中的 reposition plan。
- [ ] 在原始图像网格生成恢复后的标签。
- [ ] 支持原始空间与配准空间切换。
- [ ] 对碎片内、碎片外和 socket 位置分别验证。
- [ ] 缺少 plan 或 fragment labels 时安全降级。

验收：未移动区域的两套坐标完全一致；移动碎片上的细胞在原始空间落回真实组织，
对应脑区标签也随碎片恢复，socket 中不残留错误标签。

### 阶段 E：批量汇总报告

任务：

- [ ] 输出按阶段、类别、脑区和 tile 汇总的 CSV。
- [ ] 输出可离线查看的 HTML 报告。
- [ ] 关联截图和源文件追溯信息。
- [ ] 标记坐标警告、低 signal ratio 和接缝位置。

验收：汇总数字能逐条回溯到 `verdicts.csv`，报告不改变或重新解释人工判定。

## 13. 必测场景

- [ ] 单 tile 中央位置。
- [ ] 两个 tile 的重叠位置。
- [ ] 四个 tile 的重叠位置。
- [ ] 不同 tile z 起点。
- [ ] 通道 `offset_px`。
- [ ] 各向异性体素。
- [ ] 标签图非零 origin 和非默认 direction。
- [ ] 图像边缘和负范围裁剪。
- [ ] 坐标不被任何 tile 覆盖。
- [ ] 任意坐标附近没有最终细胞。
- [ ] s4 与最终细胞表缺行、错行或类别不同。
- [ ] 缺少 s1、s2、s3 或 s4 中任一级。
- [ ] 当前局部框内没有其它细胞或检测框。
- [ ] 空脑区和空类别过滤结果。
- [ ] fragment reposition 样本。
- [ ] 大型 CSV 的内存受控分块读取。
- [ ] GUI 中切换位置、切换 tile、截图和保存判定。

## 14. 最终验收流程

选取一批已知位置，逐个核对完整证据链：

```text
输入或点击位置
→ 全局像素坐标
→ 原始 TIFF 和 tile 局部像素
→ s1/s2 检测
→ s3 z-link
→ s4 共定位
→ 最终 cell_registration
→ labels_in_sample 脑区
→ 最终图谱位置
```

坐标链必须由自动测试精确验证。人工只负责判断原始生物信号、检测框、共定位和脑区
边界是否合理，不能依靠肉眼判断坐标换算是否“大致正确”。

## 15. 开发约束

- 不改变 brain detector 或 registration pipeline 的结果文件。
- 不让 pipeline 反向依赖本仓库。
